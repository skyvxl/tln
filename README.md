# TLN

Minimal TCP/HTTP tunnel inspired by [ngrok](https://ngrok.com/) and [tuna](https://tuna.am/).

A personal project to learn TCP/HTTP tunneling in Go.

## Pre-requisites

- Go 1.26
- [Task](https://taskfile.dev/) (optional, for running tasks)
- [golangci-lint](https://golangci-lint.run/) (optional, for linting)
